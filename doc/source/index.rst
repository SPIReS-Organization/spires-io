spires-io
=========

Data loaders and coordinate transforms for the SPIReS package family: read and
reproject MODIS / VIIRS granules (Sentinel-2 / Landsat / EMIT planned) into
``spires-contract``-validated scenes ready for inversion.

This package is part of the `SPIReS family <https://spires.readthedocs.io/>`_.
